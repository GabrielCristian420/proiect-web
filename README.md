Ce scrieti in terminal ca sa porniti local site-ul:
1. git clone https://github.com/GabrielCristian420/proiect-web
2. cd proiect-web
3. python -m venv venv (trb doar 1 data)
4. venv\Scripts\activate 
5. pip install -r requirements.txt (trb scrisa doar o data ca sa instalati librariile necesare)
6. python -m flask run --debug
